# Roadmap

## Public beta — v0.90.x

- stabilize CLI/JSON contracts
- collect installation and integration feedback
- improve documentation and portability
- fix security or compatibility issues discovered by public testing

## 1.0 readiness

A 1.0 release should require:

- no known data-loss defects
- stable command schema and data schema
- successful fresh-install and upgrade testing
- public documentation reviewed by at least one user other than the original developer
- REST API security assumptions clearly understood by operators

Possible post-1.0 work includes richer client libraries, web/mobile front ends, additional import adapters, and optional visualization components.
