# Support

Weight Tracker is free, open-source software released under the MIT License.

## Getting Help

For usage problems or bug reports, please use GitHub Issues.

Include:

- `weight_tracker version`
- sanitized `weight_tracker doctor` output
- the command that failed
- the error message

Do not include a database, export file, API token, chat ID, name, weight history, food history, notes, or other private wellness data.

For security issues, follow `SECURITY.md`.

## Supporting Development

Weight Tracker is free to use and does not require payment, a subscription, or a hosted account.

If you find the project useful and would like to support its continued development, optional sponsorship is available through GitHub Sponsors.

Sponsorship does not unlock features or change the software license. The complete project remains available under the MIT License.

Thank you for supporting open-source development.
